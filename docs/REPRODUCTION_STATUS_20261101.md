# ROSA再現実装：機能・性能・問題の一覧

確認日：2026-11-01 JST。対象論文は arXiv:2607.01088v1。保存済みソース・試験報告と論文を照合した。新しいGPU試験、Podへの接続、保存済み生ログの追加実行監査は行っていない。

**到達点は、ROSAの中核機構を独立実装し、単一GPUで実モデルとLIBEROシミュレーションを接続した機能プロトタイプである。論文全体の機能・性能の再現完了、または最終構成の安定稼働を示す結果ではない。**

「実装あり」「CPUで動作確認」「実GPUで動作確認」「論文条件で性能再現」を分ける。CPUの人工モデルによる結果を、実モデルの性能や操作成功へ読み替えない。

## 3. 性能・品質の達成状況

| 評価項目 | 今回の結果 | 結論 |
|---|---|---|
| P1・共有S1の期限内動作 | 4環境、30秒測定、223適格行動、Q=7.4333/s。測定要求224件のp99=120.16ms、200ms期限全件達成。 | 縮小条件の実動作を確認。1セル1,000件未満の探索的試験で、論文の性能再現値ではない。 |
| P2〜P4の成分別期限 | 回復機構追加前のv0.20.8で300秒×3回すべて観測p99目標達成。最悪p99はS1 198.28ms、Safety 218.43ms、S2 1,132.70ms、Monitor 840.86ms。 | 固定した単一GPU拡張条件で達成。ただしS1の個別期限超過15件があり、全要求の期限保証ではない。 |

## 4. 取り組みの中で発生・判明した問題

| 問題 | 観測・原因の根拠 | 対処と残存状況 |
|---|---|---|
| 単一GPUでのモデル競合・待ち時間 | 初期FIFOでは複数成分が約8〜10秒に達し、P2〜P4のQ=0。 | 出力短縮、役割並行、位相分散、MPS、S1バッチを追加。旧構成のp99は達成したが、回復付き最終構成の全条件安定達成には至らず。 |
| 速度改善時の意味出力変化 | 同じ画像でもSafety/Monitorの短縮形式で判定が変化。3文字Safety出力は人物・衝突ラベルが崩れた。 | 3文字案は不採用。採用した短い形式も、人手ラベルによる意味品質確認が必要。 |
| VLMだけでは停止を解消できない | MuJoCo追加前にQwen3-VL-4B/8Bを各120秒試したが、本測定のP3/P4停止率は両方100%。 | 単なるモデル世代変更で解決した証拠はない。既定モデルを変更せず、幾何検査を別拡張として導入。 |

| P3の退避後「視界不明」 | 再計画用feedbackがSafetyにも渡っていた。同じ画像でその情報だけを除くとclearへ変化。 | feedbackをS2だけへ限定。v0.20.16探索・確認1・確認2は各600判定で視界不明0。今回の条件で改善したが、一般的な認識精度の証明ではない。 |

| タスク終了時のMonitor欠測 | 終了直前の観測保存をまたいで送信時刻になり、終了通知で予定済み要求を落とす。最新確認2は148/150=98.67%。 | v0.20.17で修正しCPU関連45テスト通過。Pod未配置・GPU未検証のため解決済みとしない。 |

## 5. 独自拡張として区別する範囲

単一GPUへの全成分同居、MPSと位相分散による同居調整、MuJoCoの接触・距離予測、2mm基準、状態照合付き実行承認、独立した退避動作とその制限は、本プロジェクトの実装・実験条件である。ROSAのfallbackという考え方に対応する部分はあるが、これらの具体的な安全判定・回復方式が論文と同一とは主張しない。

最も正確な成果表記は「ROSAの論文記述に基づく独立再実装。中核スケジューラはCPU検証済み。共有推論・実モデル・シミュレータの単一GPU接続は検証済み。P2〜P4同居と幾何安全・回復は独自拡張。論文性能の再現と最終構成の安定性・意味品質の確認は未完了」である。
