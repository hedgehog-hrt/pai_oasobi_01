# P3再停止と期限改善の検証条件

2026-11-01。ユーザーから、P3の視界不明による再停止と期限未達を改善し、条件を満たしたら300秒×3回確認する指示を受けた。

v0.20.14は、再計画メッセージをS2だけへ渡し、Safetyの同一モデル内で最大2要求を並行処理する。次エピソードの通常hard resetは別のシミュレータprocessで事前実行する。S1は変更せず、Safetyの画像・モデル・指示文・判定形式・未知時停止・MuJoCoの2mm/2ms検査・時間予算も変更しない。

保存画像の比較では、退避後の再計画メッセージを取り除くとP3再停止画像のvisibilityがunknownからclearになった。黒画像はunknownのまま。文字コードで出力を短縮する案は正常場面でもperson=unknown/collision=presentとなったため不採用。soft resetは内部状態の完全一致を確認できず不採用。通常hard resetの先行実行は、画像・復元状態・15チャンクの衝突予測と継続軌道が一致した。

## 事前固定するゲート

探索はウォームアップ60秒＋測定300秒、既存探索状態0〜9、P2/P3/P4各1台。元S1停止率と退避後停止率を別々に報告する。P3/P4それぞれ100判定以上、元S1停止率90%以下、全成分p99が既存期限内、周期成分の成立率99%以上、正常終了・監査・GPU監視・MPSを必須とする。S1は200ms、Safety500ms、S2/Monitor2000ms。要求頻度や分母を変えて合格にしない。

回復機能は各P3/P4で退避後3チャンクのS1再開を確認する。自然な探索で退避が発生しなかったクラスは、過去の停止状態からの独立した実モデル回復検証で補う。その検証は探索・確認の停止率や成功率へ加えない。探索で実際に発生した退避が継続再開に失敗した場合は、別検証でその失敗を置き換えない。

これらを満たしたソース・設定を固定して確認300秒×3回へ進む。確認では既存状態20〜49、反復番号0/1/2を使う。過去試験にも使った状態のため未知状態への一般化とは主張しない。性能上の失敗も残して予定3回を評価し、失敗を追加試行で置き換えない。モデル・シミュレータの整合性や後処理に問題が出た場合は、それを直して別実験として扱う。

## v0.20.15の追加探索

v0.20.14の探索300秒はP3の退避後3チャンク再開を確認したが、S1 p99がP2 211.57ms、P3 201.09msで未達だった。この失敗を保存し、S2/MonitorのMPS client priorityを1（below normal）、S1/Safetyを0（normal）に固定した別実験を行う。モデル・画像・頻度・期限・Safety条件は同じ。priorityはCUDAドライバへのヒントであり、実行順や期限の保証ではない（[NVIDIA公式仕様](https://docs.nvidia.com/deploy/mps/appendix-environment-variables.html)）。

VLMの設定指紋、実行計画、エンジン起動時の環境、GPU worker初期化時の実環境とPIDを記録する。起動時の一時変更は親プロセスへ残さず、明示したMPS環境がなければ失敗する。実測中にMPSへ接続したPIDとGPU workerの証跡を照合する。既存のprofileは採用せず、同じ探索条件と確認前ゲートを適用する。回復機能は終端成功の有無も記録するが、確認試験への入場には元の3チャンク再開条件を維持する。

## 確認前の評価補足（探索を見た後の変更）

v0.20.15の探索でP4は最後の退避後2チャンクでシミュレータのタスク成功に到達した。このため、上記の「3チャンクのみ」の入場条件ではP4は未達となる。これを隠さず、2026-10-31 18:25 UTC、確認試験の開始前に `confirmation-criteria-supplement.json` と `confirmation-admission.json` へ評価補足を記録した。探索に先立つ事前登録条件とは扱わない。

補助的な回復判定は、同一エピソード内の最後の退避後に「次の退避までにS1を3チャンク適用」または「実行ステップが既知のS1適用でシミュレータのタスク成功に到達」とする。後者には、その最終S1行動の終了時刻とエピソード成功時刻の一致を要求する。時間切れ、ステップ上限、測定打切り、退避だけでの成功は代用しない。途中の退避、3チャンク未達、継続したがタスク未達の事例はそれぞれ記録する。

元の停止率、3チャンク再開数、期限、頻度、衝突閾値は変更しない。タスク完了を3チャンク再開として計上しない。実際に未回復のまま終わった退避列を独立検証で置き換えない。確認3反復は、この補足を固定してから開始する。探索ではP3/P4とも自然に回復が発生したため、準備した別の強制条件検証は実行しない。
