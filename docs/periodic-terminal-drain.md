# エピソード終了時の周期要求

v0.20.16の固定確認では、P3のMonitorがタスク終了付近で欠測した。最終観測の保存が周期時刻をまたぐと、終了通知が先に処理され、すでに予定時刻を過ぎた要求も取り消されていた。CPUの閉ループで同じ状況を再現し、修正前は対象スロットが欠測することを確認した。

v0.20.17は終了通知時点ですでに予定時刻に達した周期要求を、同じエピソードの最終観測で完了してからセッションを切り替える。まだ予定時刻に達していない要求は発行しない。元のscheduled_ns、期限、周期、計測窓、監査器は維持し、遅れた要求を時刻の書き換えで救済しない。実行中のS1や物理制御、退避候補・距離・回数制限は変更しない。

回帰テストは、欠測の再現に加え、最終観測を使用すること、元の予定時刻と期限を維持すること、未来のスロットを先取りしないこと、同じスロットの二重発行や別エピソードへの持ち越しがないことを検証する。既存の閉ループ・回復テストと合わせ、隔離した修正候補で37件が通過した。GPUでの結果は別に記録し、CPU検証をGPUでの達成とは扱わない。
